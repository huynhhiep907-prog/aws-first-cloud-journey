**Trong trang này**, bạn sẽ tìm thấy tổng quan về những công việc đã thực hiện trong chương trình FCAJ. Nhật ký công việc kéo dài 11 tuần, từ giai đoạn làm quen với chương trình và kiến thức nền tảng AWS đến quá trình triển khai, rà soát workshop Bếp Thông Minh.

**Tuần 1:** [Làm quen với FCAJ, tìm hiểu yêu cầu chương trình và thành lập nhóm dự án](1.1-Week1/)

**Tuần 2:** [Tìm hiểu điện toán đám mây, các nhóm dịch vụ AWS, hạ tầng toàn cầu, IAM và truy cập an toàn](1.2-Week2/)

**Tuần 3:** [Tìm hiểu kiến thức mạng AWS, Amazon VPC, máy chủ EC2 và lưu trữ EBS](1.3-Week3/)

**Tuần 4:** [Tìm hiểu lưu trữ đối tượng Amazon S3, kiểm soát truy cập, versioning và bảo vệ dữ liệu](1.4-Week4/)

**Tuần 5:** [Tìm hiểu phân phối nội dung CloudFront, caching, DNS, HTTPS và xử lý sự cố website](1.5-Week5/)

**Tuần 6:** [Tìm hiểu điện toán serverless, AWS Lambda, execution roles và giám sát](1.6-Week6/)

**Tuần 7:** [Tìm hiểu REST API và tích hợp Amazon API Gateway với AWS Lambda](1.7-Week7/)

**Tuần 8:** [Tìm hiểu mô hình dữ liệu DynamoDB, truy vấn, indexes và truy cập bằng Boto3](1.8-Week8/)

**Tuần 9:** [Khám phá Amazon Location Service, giám sát CloudWatch, bảo mật AWS và quản lý chi phí](1.9-Week9/)

**Tuần 10:** [Bắt đầu workshop Bếp Thông Minh, rà soát phạm vi, frontend, backend và kiến trúc triển khai AWS](1.10-Week10/)

**Tuần 11:** [Kiểm thử các chức năng Bếp Thông Minh và hoàn thiện proposal, sơ đồ kiến trúc, ước tính chi phí AWS](1.11-Week11/)
