### Week 8 Objectives:

* Consolidate knowledge of security, monitoring, and cost management for an application built with AWS services.
* Explore the potential use of Amazon Bedrock and prepare the technical knowledge needed before the Workshop phase in Weeks 9–11.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 1 | - Study the AWS Well-Architected Framework and its six pillars.<br>- Focus on Security, Reliability, Performance Efficiency, and Cost Optimization when reviewing an application design.<br>- Identify questions that can be used to assess the proposed solution. | 11/02/2026 | 11/02/2026 | [AWS Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html) |
| 2 | - Explore Amazon CloudWatch metrics, logs, and alarms.<br>- Identify useful monitoring information for Lambda functions and API requests.<br>- Understand how logs and alarms help detect errors and unusual resource usage. | 11/03/2026 | 11/03/2026 | [What is Amazon CloudWatch?](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/WhatIsCloudWatch.html) |
| 3 | - Learn how to use AWS Pricing Calculator to estimate service costs.<br>- Review the assumptions needed for estimates, such as request volume, execution duration, storage, and data transfer.<br>- Distinguish an estimate from actual charges shown in billing. | 11/04/2026 | 11/04/2026 | [AWS Pricing Calculator](https://docs.aws.amazon.com/pricing-calculator/latest/userguide/what-is-pricing-calculator.html) |
| 4 | - Study AWS Budgets and Cost Explorer.<br>- Learn how budgets, thresholds, and alerts can help monitor service spending by service or Region.<br>- Review how to identify unexpected usage before it becomes a larger cost. | 11/05/2026 | 11/05/2026 | [Cost Management](https://docs.aws.amazon.com/cost-management/latest/userguide/what-is-costmanagement.html) |
| 5 | - Explore Amazon Bedrock at a high level, including foundation models, model access, and inference requests.<br>- Review the basic API-based integration approach.<br>- Note that model access and quota must be confirmed before treating Bedrock as an available project feature. | 11/06/2026 | 11/06/2026 | [What is Amazon Bedrock?](https://docs.aws.amazon.com/bedrock/latest/userguide/what-is-bedrock.html) |
| 6 | - Review the overall request flow across the frontend, API Gateway, Lambda, DynamoDB, and Amazon Location Service.<br>- Summarize remaining questions about permissions, API errors, data access, and cost monitoring.<br>- Prepare a list of topics to validate during the Workshop phase in Weeks 9–11. | 11/07/2026 | 11/07/2026 | [AWS Lambda](https://docs.aws.amazon.com/lambda/latest/dg/welcome.html)<br>[Amazon DynamoDB](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/Introduction.html)<br>[Amazon Location Service](https://docs.aws.amazon.com/location/latest/developerguide/what-is.html) |

### Week 8 Achievements:

* Learned how the Well-Architected Framework can be used to review an AWS solution.
* Understood the role of CloudWatch in monitoring metrics, logs, and alarms.
* Became familiar with cost estimation and monitoring through Pricing Calculator, AWS Budgets, and Cost Explorer.
* Gained an overview of Amazon Bedrock and recognized the need to confirm model access and quota before integration.
* Consolidated the AWS knowledge required for the practical Workshop planned for Weeks 9–11.
